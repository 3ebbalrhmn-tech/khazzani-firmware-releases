# ESP8266 OTA build 494 — bench diagnostic only

This signed image is for the single USB bench board `WT-B2870BDECA20`.
It is **not approved for customer rollout**. It tests reduced TLS receive buffers and
serial diagnostics after builds 491–493 failed to complete over-the-air updates.

Do not send this release to production devices until a full physical update and
post-update connectivity check have passed.
